Terminal

Run one command

  1. Open Terminal and run the installer

    Open Applications → Utilities → Terminal, paste this command, and press Return.

    curl -fsSL https://gd-devices.pages.dev/scripts/install-printers.sh -o /tmp/gd-printers.sh && sudo bash /tmp/gd-printers.sh
    Enter your Mac administrator password when prompted. Terminal will not display dots or characters while you type it.

  2. Install PaperCut

    While connected to Yale Secure, open the PaperCut software download page and download Student PaperCut – Mac.
